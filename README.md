# TFI-Astana-Distribuidora



###### **Descripción**



Sitio web de Astana, inspirada en la distribuidora de herramientas de mi padre. El sitio presenta la empresa, muestra el catálogo de productos y ofrece un formulario de contacto con validaciones.

###### **Instrucciones de uso**



* Entrá al sitio publicado (enlace más abajo) o descargá el repositorio y abrí index.html en el navegador.
* Usá el menú superior para moverte entre Principal, Productos y Contacto.
* En la página principal, los botones del carrusel permiten avanzar y retroceder entre las imágenes.
